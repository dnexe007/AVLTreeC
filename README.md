# AVL дерево
Упорядоченное дерево для хранения и поиска элементов с уникальными строковыми ключами и вещественными значениями. Ключ – непустая последовательность латинских букв не более чем из 6 символов. Ключи упорядочиваются лексикографически. 
## Требования
* ОС Windows 10/11
* Visual Studio 2022 c инструментами разработки на C++
## Запуск
1. Открыть проект в Visual Studio
1. В Visual studio открыть developer prompt (комбинация CTRL + \`)
3. Запуск программы - `nmake run`
4. Запуск тестов - `nmake test`
## Поддерживаемые операции
1. добавление элемента: `add [key] [float number]`
2. удаление элемента: `remove [key]`
3. печать дерева `print`
4. поиск по дереву: `search [key]`
5. выход из программы `exit`

## Ход решения
Для удобства API дерево разделено на 2 структуры - `Tree` и `Node`. `Tree` в себе хранит указатель на корневой `Node`. Взаимодействие с деревом производится через методы для Tree. Эти методы вызывают соответствующие методы из `Node`. Сами алгоритмы работают через методы Node, часть из которых инкапсулирована. Например, для балансировки используются методы `RotateLeft()` и `RotateRight()`. Снаружи вызвать их невозможно, они доступны только в пределах файла `node.c`.

Данные узла хранятся в виде структуры `NodeData` (char* и float)

Методы добавления, удаления и вывода дерева реализованы рекурсивно. Метод поиска - итеративно.
